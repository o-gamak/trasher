# T-Invest Junk Bond Scanner

Программное решение для автоматизированного сканирования рынка рублевых облигаций через API Т-Инвестиций. Скрипт осуществляет поиск инструментов с высокой доходностью, рассчитывает эффективную доходность к погашению (YTM), присваивает каждой бумаге рейтинг Junk Score и формирует диверсифицированный портфель.

## Архитектура обработки данных

Реализован трехслойный конвейер (Three-Layer Pipeline) для обеспечения целостности данных и возможности автономной работы:

1. L1: Raw JSON (data/download.json) — Прямой дамп ответов сервера. Содержит полные объекты инструментов, актуальные цены и календарь выплат.
2. L2: Parsed CSV (data/download_data.csv) — Денормализованные данные. Таблица всех найденных облигаций с рассчитанными финансовыми метриками.
3. L3: Ready CSV (data/ready_data.csv) — Финальный результат. Оптимизированный портфель с учетом лимитов концентрации на одного эмитента и бюджетных ограничений.

## Инструкция по запуску

Управление скриптом осуществляется через Hydra. Параметры можно изменять в config.yaml или передавать как аргументы командной строки.

### Обновление базы данных (API Mode)
Для выполнения полного цикла сканирования и обновления локального кэша:
python src/vibecode_test/trasher.py app.load_data=true

### Анализ из локального кэша (Offline Mode)
Для изменения параметров фильтрации без обращения к серверу (защита от лимитов API):
python src/vibecode_test/trasher.py app.load_data=false scanner.min_ytm_annual=25

### Фильтрация дефолтных инструментов
Для исключения бумаг с аномальной доходностью, свидетельствующей о реализованном дефолте:
python src/vibecode_test/trasher.py scanner.max_ytm_annual=100

## Методология расчетов

### Yield to Maturity (YTM)
Расчет выполняется на основе полной стоимости владения инструментом:
YTM = ((Nominal - Purchase_Price) + Total_Future_Coupons) / Purchase_Price / Years_to_Maturity * 100

### Junk Score
Интегральный показатель (от 0 до 100), определяющий приоритет включения в портфель:
- Доходность (50% веса): Пропорционально значению YTM относительно целевого порога.
- Срочность (30% веса): Премия за инструменты с периодом обращения 9–15 месяцев.
- Дисконт (20% веса): Премия за существенное отклонение рыночной цены от номинала (ниже 90%).

### Модель устойчивости (Стресс-тест)
Алгоритм проводит проверку гипотезы дефолта 33% портфеля (наиболее рискованные позиции по YTM). Портфель считается валидным, если процентный доход по остальным позициям перекрывает убытки от потери номинала дефолтных бумаг.

## Ключевые параметры конфигурации

Параметры секции scanner и portfolio:
- api.sandbox: переключение между тестовой и реальной средой.
- scanner.min_ytm_annual: минимальный порог доходности для входа.
- scanner.max_ytm_annual: верхний лимит доходности (фильтр неликвидных данных).
- portfolio.budget: общий объем выделяемых средств.
- portfolio.slots: целевое количество уникальных позиций.
- portfolio.max_per_issuer: максимальное количество выпусков одного эмитента.

## Отказ от ответственности
Данное ПО является инструментом автоматизации расчетов и не является инвестиционной рекомендацией. Торговля высокодоходными облигациями сопряжена с риском полной потери капитала. Режим исполнения заявок по умолчанию — dry_run=True.
